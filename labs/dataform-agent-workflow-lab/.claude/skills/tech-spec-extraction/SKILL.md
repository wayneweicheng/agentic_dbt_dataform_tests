# Tech Spec Extraction Skill

Use this skill when converting a technical specification into implementation requirements.

## Steps

1. Identify objective and target output.
2. Extract source tables, columns, and grain.
3. Extract filtering, deduplication, null handling, and aggregation rules.
4. Extract acceptance criteria and scenario requirements.
5. Return structured notes with assumptions and unresolved questions.
