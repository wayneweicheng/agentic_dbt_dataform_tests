# Scenario Test Generation Skill

Use this skill to derive test scenarios from a technical specification.

## Steps

1. List every acceptance criterion.
2. Map each criterion to scenario rows.
3. Create source sample data for each rule.
4. Create target comparison data at the output grain.
5. Record coverage in markdown.

## Artifacts

- scenario coverage markdown
- source sample CSV
- target comparison CSV
